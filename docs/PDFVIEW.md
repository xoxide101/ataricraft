# PDF viewer (high resolution, offline)

Open `web/pdfview.html` (side panel tab **PDF**, or `?src=URL` to open a PDF by URL). Everything runs in the browser, including from `file://`; nothing is uploaded.

## What it does

| Feature | How |
|---|---|
| Open | **Open** button, drag and drop a `.pdf` onto the page, or **Library** (PDFs you opened before, kept in IndexedDB on this browser only) |
| High resolution | Each page is rendered to a canvas whose backing store is `zoom x devicePixelRatio` (HiDPI/Retina crisp), capped at 24 megapixels per page |
| Zoom | `-` / `+` buttons, Ctrl+wheel, presets 50 to 800 %, **Fit width**, **Fit page** |
| Page navigation | previous/next, page number box, scrolling updates the current page |
| Text search | case-insensitive, counts every hit ("2 / 3"), up/down jumps between hits; the text layer also lets you select and copy text |
| Send to Atari | dithers the current page to a 320x192, 2-shade GR.8 picture (palette.js + imgconv.js, the same converter as the Workbench Images tab; options Dither and Invert) and previews it. **Send to emulator** boots a viewer in the emulator tab that opened this page (`postMessage` `ac-boot`); or download a self-running `.XEX` viewer (ANTIC mode F), the raw `.GR8` (7680 bytes) or a PNG. The page is fitted whole, or cut into tiles (page scaled to 320/640/960/1280 px wide, step through the tiles) |

## Files

| Path | Role |
|---|---|
| `web/pdfview.html` | page and styles |
| `web/js/pdfview.js` | viewer logic (loading, layout, rendering, search, library, Send to Atari). Exposes `window.PDFVIEW = { open(bytes, name), state }` |
| `web/js/pdfjs/pdf.min.js`, `pdf.worker.min.js` | vendored **pdf.js 3.11.174** (legacy-compatible UMD build) |
| `web/js/pdfjs/LICENSE-pdfjs-Apache-2.0.txt` | pdf.js licence |

| `docs/samples/pdf-test.pdf`, `scripts/mk-sample-pdf.cjs` | 3-page test document (generated by the script, no third-party content) |
| `scripts/pdfview-test.cjs` | end-to-end test |

## Licence

pdf.js is by Mozilla and contributors, **Apache License 2.0**. That allows redistribution in this repository as long as the licence text and the copyright notices stay with it: the licence is in `web/js/pdfjs/LICENSE-pdfjs-Apache-2.0.txt` and the `@licstart` header at the top of each minified file is untouched. The files are unmodified upstream builds (npm package `pdfjs-dist@3.11.174`). 3.x was chosen because it is a classic script (works from `file://` with no ES-module or Worker restrictions). To upgrade, replace the two files, keep the licence, and run the test.

Worker note: `pdf.worker.min.js` is loaded by a normal `<script>` tag, so pdf.js sees `pdfjsWorker` on the page and runs the worker code on the main thread. Chrome blocks `new Worker()` from `file://`, so this is what keeps the viewer working offline without a server.

## Reusing the PDF module (EBookCraft and others)

Load three scripts in this order, paths relative to the page:

```html
<script src="js/pdfjs/pdf.min.js"></script>
<script src="js/pdfjs/pdf.worker.min.js"></script>
<script src="js/pdfjs/pdfengine.js"></script>
```

`PDFENGINE` (no UI):

```js
await PDFENGINE.pageCount(bytes)            // number of pages
await PDFENGINE.pageText(bytes, 2)          // text of page 2 (1-based)
await PDFENGINE.renderPage(bytes, 1, 150)   // { w, h, rgba } at 150 dpi (72 PDF points = 1 inch), white background
```

`renderPage` matches the contract EBookCraft already defines in `web/js/ebookcraft/ebc-pdf.js`, so enabling high-resolution page rendering there is one line once the three scripts are on its page: `EBC.pdf.engine = PDFENGINE;`. The last opened document is cached by `bytes` identity, so rendering many pages of one file does not re-parse it. For anything richer (text layer, annotations) use `window.pdfjsLib` directly, as `pdfview.js` does.

## Test

`node scripts/pdfview-test.cjs` (Chrome through Playwright, `file://`, device scale factor 2). Checks: page count, canvas is 2x the CSS size, rendered ink (text and coloured boxes), real text in the text layer, case-insensitive search with hit counts, page navigation, 400 % zoom stays crisp, Atari preview and tile grid, XEX layout (FFFF header, 7680 data bytes, RUNAD), library save and reopen, `PDFENGINE`, drag and drop, boot in the emulator (display list at `$3F00`), no page errors. Screenshots go to `out/pdfview-*.png`; one is kept at `docs/screenshots/pdfview.png`.

## Limits

Password-protected PDFs are not handled (no prompt). Very large pages are rendered at reduced backing resolution. Send to Atari is a dithered 1-bit-class picture, meant as a preview on real hardware, not for reading small text.
