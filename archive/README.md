# Disk archive
- `blank/` - empty formatted MyDOS and SDFS images (90K to 16M), generated by `scripts/make-archive-disks.cjs`, verified with our reader and lsatr. See MANIFEST.txt for hashes. Not bootable: boot a DOS disk, then use these as data drives.
- `boot/` - local-only DOS boot disks (MyDOS 4.55b4, BW-DOS, SpartaDOS 4.43). Third-party software, so ignored by git. Rebuild blank disks any time with the script.
