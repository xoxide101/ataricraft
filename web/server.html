ataricraft · server library builder

Builds the index (catalog.sqlite) and library.json that the app needs when it is served from a web server. Nothing is uploaded anywhere: this page reads the library folder and writes the two files back into it.

This page needs the folder picker, which Chrome/Edge only allow on https, localhost or a local file:// copy. Open server.html from your own computer's copy of the web folder (double-click it), not through the NAS address.

1. Pick the library folder

The folder on the server (a mapped network drive or share is fine) that holds software/, roms/, dos/, bios/ and basic/. Any other sub-folder names work too: the folder name is the first part of every path, so the app finds it on the server without any mapping.

2. Choose which folders to include

pick a folder first

3. Build




Zip and 7z files are listed by reading their directory only; nothing is extracted. Run this again whenever you add or remove files. Copy the whole web folder (including js) to the server; library/ goes beside index.html.
