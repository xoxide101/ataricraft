The hybrid Craft apps are a core proof of concept for the actual system, using very specific data: each shows that the web side and the Atari side can be used together. All of these tools are ways to manipulate existing data and move it into and out of the system from current standards. The goal is to bring the evolved apps to the main system with the same features and a way to present them correctly.
